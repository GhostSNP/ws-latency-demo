# ws-latency-demo

Минимальный asyncio + WebSocket стенд для замера задержки (RTT) на потоке «аудио-чанков».

Клиент шлёт 640-байтные чанки каждые 20 мс (как 16 кГц / 16 бит / mono),
сервер сразу возвращает их, клиент считает mean / p50 / p95 / p99 / max.

## Запуск
```
pip install -r requirements.txt
python server.py          # терминал 1
python client.py          # терминал 2
```

## Результат (localhost, Windows 11)
500/500 чанков, RTT mean ≈ 1.03 мс, p95 ≈ 1.41 мс, p99 ≈ 1.62 мс, max ≈ 3.67 мс.
Это нижняя граница (loopback, без модели и сети).

## Идеи для развития
- искусственная задержка/потери, чтобы смотреть p95/p99 под нагрузкой
- несколько клиентов одновременно
- тест-режим «до/после»: падает ли скорость после изменения пайплайна
